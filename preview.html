I spent some time digging into why the incremental build regressed after we split the app into feature modules. The short version is that the module graph is fine, but every target re-emits the shared Design module's interface file, so downstream targets always look dirty to the build system.

Two options. We can stop re-emitting by pinning the interface output path per configuration, which is a two-line change but makes clean builds slightly slower. Or we can split Design into a tokens-only target that almost never changes and a components target that does — bigger change, but it fixes the underlying fan-out instead of hiding it.

I lean towards the second, since we will hit the same wall again when the iOS app lands. Happy to be talked out of it if someone has numbers.
